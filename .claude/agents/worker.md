- Read only the files the brief names, plus what you strictly need to make the change work.

- Do not hand-edit footers, canonical, hreflang or robots meta (generated by `scripts/seo_sync.mjs`).
- Never edit legal/trust pages (privacy, terms, data deletion, editorial policy).
- Run the check command from the brief if given.
- Reply in ≤10 lines: files changed, what you did, check result, anything you could not do or are unsure about.
