# Docs index

One line per doc: when to read it. Keep each doc focused and under ~150 lines.

- `architecture.md` — read when changing page structure, shared JS/CSS, tools, or the SEO scripts.
- `domain.md` — read when writing/editing content: audience, goal, locales, tools, health-copy rules.
- `decisions.md` — read before reversing or questioning an existing design choice.
- `publishing.md` — read when adding or updating an article or tool page (end-to-end checklist).
- Existing SEO playbooks (owner-maintained): `../seo-operations.md`, `../seo/content-calendar.md`,
  `../seo/backlink-sprint.md`, `../seo/traffic-scorecard.md`.
- `analytics.md` — read when using Search Console/Mixpanel data (`analytics` skill), setting up credentials or the weekly run.
- `ai-visibility.md` — read when working on AI-assistant visibility (llms.txt, AI crawlers, IndexNow, baseline prompts).
- `indexing.md` — read when pages aren't indexed: re-run the site audit (`analytics:audit`), GSC sitemap status, causes per non-indexed page.
